Cómo narrarlo (frases en inglés listas) P0
MomentoFrase
Abrir“Let me first get a top-level view of the structure before changing anything.”
Patrón“This follows an MVC / layered structure: controllers, services, DTOs, entities.”
Priorizar“I see three issues: one is a real bug, one is a safety concern, and one is design. I’ll start with the bug.”
REST“Since this is a POST that creates a resource, it should return the created transaction, not a string.”
Naming“I’d rename this to createTransaction, since functions should describe the action.”
SRP / CQS“This is called get but it writes to the database. That side effect is misleading, so I’ll split it.”
DRY“The commission logic is duplicated, so I’ll extract it into one pure function.”
Promise“This return happens inside the subscribe callback, so the method actually returns undefined. I’ll wrap it in a Promise and resolve it from the callback.”
Encapsulación“The EUR rule belongs to the exchange service. Right now its logic leaks into this service.”
any“I’ll leave any here for speed, but in production I’d use a proper DTO type, because any disables type safety.”
Fintech“Money shouldn’t be a float. I’d use integer cents or a decimal type, and add an idempotency key so retries don’t create duplicates.”
Sin compilar“This might not compile yet, but the intent is X. I’ll fix the types after the structure is right.”
Qué dominar antes de la sesión (según el video) P0
  1. REST aplicado: saber si un endpoint es o no RESTful y corregirlo (verbos, status codes, qué devuelve cada método). Ver tabla abajo.
  2. SOLID en la práctica (sobre todo SRP), sin purismo: aplicarlo a código concreto. → 13
  3. Fundamentos JS: async/await, Promises, el constructor new Promise, this. → 01
  4. Velocidad: practica refactors cronometrados; con nervios vuelves a las prácticas que tengas automatizadas.
  5. Cada decisión = una buena práctica que puedes nombrar.
