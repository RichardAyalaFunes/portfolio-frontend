Versiones de Node: cambiar, fijar y forzar P0
Corrección clave: npm no cambia la versión de Node (npm viene dentro de Node). npm sólo puede exigir/validar una versión (engines + engine-strict). Para cambiar se usa un version manager: nvm, nvm-windows, fnm o Volta.
