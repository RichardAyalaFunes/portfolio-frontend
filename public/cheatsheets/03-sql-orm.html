N+1 — el bug de ORM más preguntado

Transacción en Sequelize (stack del JD)

Error clásico Sequelize: olvidar { transaction: t } en una query → corre fuera de la transacción con otra conexión (y puede bloquearse esperando el lock de la propia tx). Solución global: CLS (Sequelize.useCLS(namespace)).
