Errores frecuentes

'use client' marca una frontera: todo lo que ese archivo importa también es cliente. Ponla lo más abajo posible en el árbol. Un Client puede recibir Server Components como children.
Layouts, loading, error P1
Fetching de datos P1
Next 15: fetch ya no se cachea por defecto (en 14 sí). Las páginas que leen cookies()/headers()/searchParams son dinámicas. Ver caché en 06.
Anti-patrón: Server Component haciendo fetch('http://localhost:3000/api/...') a su propio Route Handler. Llama a la función de datos directamente.
Route Handlers (API) P1
Webhooks: lee el body crudo con await req.text() antes de parsear, para verificar HMAC. Un Route Handler GET no se cachea por defecto en 15.
