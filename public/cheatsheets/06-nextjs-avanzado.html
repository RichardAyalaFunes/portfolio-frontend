Server Actions P2
Una Server Action es un POST público con un ID. bind(null, fromId) NO es seguro: el cliente puede enviar otro fromId. Siempre re-autoriza dentro. Usa Actions para mutaciones; para lecturas, Server Components.

Seguridad en Next P2
  • Server Actions: Next compara Origin con Host (CSRF básico); configura serverActions.allowedOrigins tras proxies.
  • No pases objetos de DB completos a Client Components: todo lo que cruza la frontera llega al navegador. Usa DTOs.
  • import 'server-only' en módulos con secretos/DB.
  • taintObjectReference / taintUniqueValue (React experimental) evitan filtrar objetos sensibles.
  • Headers: CSP, X-Frame-Options, HSTS en next.config → headers().
  • dangerouslySetInnerHTML con input del usuario = XSS. React escapa por defecto.
  • Rate limiting en Route Handlers de login/pagos (Upstash, Redis, WAF).
